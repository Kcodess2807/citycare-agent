     any write that was interrupted in an earlier turn by running its verify. It

     turn fails with step_limit or budget.
  3. _call_model (loop.py:256) is wrapped in with_retries (retry.py). 408, 409,
     429 and 5xx are retried twice with backoff. A 400 is not retried.
     before_model and after_model hooks run around it via _check, and a Block
     from either fails the turn as hook_blocked. If retries run out, the turn
     fails as model_error.
  4. The model returns tool_use: book. _run_tools (loop.py:288) calls _one_call
     (loop.py:313). registry.parse (tools.py) validates the input. If it's
     invalid, the model gets a readable error and tries again. A call repeated 3
     times in a turn is refused.
  5. The before_tool hook pauses. HookRunner.run (hooks.py) calls the ownership,
     confirmation and 4-hour-rule hooks in agent_service. These are Phase 3 and
     not built. The confirmation hook returns Pause(reason, payload). The
     payload holds the params, the read-back facts and the idempotency key. If a
     hook crashes, times out or returns None, that counts as a Block (fail
     closed). _hold_pause (loop.py:342) checks the payload is JSON and keeps it
     in memory only.
  6. The model writes the read-back and ends its turn. _finish (loop.py:352)
     saves pending to the state first, then calls _commit (history). If the
     history commit fails, _put_back restores the old pending. The result is
     status="paused".

  Turn B: the patient says "yes"

  7. Recognising the yes is not built. It is a Phase 3 decision, still open in
     the design log. The plan is for code to run the stored payload through
     execute_tool(name, input). That uses the same registry, hooks and trace,
     and the result goes to the model as plain text. If code mismatches the yes
     with the pending action, there is no defined behaviour yet.
  8. Executor.execute (executor.py:61) first checks the budget against reserve_s
     (about 30s). If there's too little time, nothing runs and the result is
     Failed(escalate). Otherwise _unit (executor.py:109) runs shielded from
     cancellation. It saves inflight first, and if that save fails the write
